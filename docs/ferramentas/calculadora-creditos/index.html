Premissas e fontes

Cowork e GitHub Copilot Harness assumem 22 dias úteis por mês e Anthropic Opus 4.8 na referência. Standard utiliza os medidores por recurso. O orçamento não inclui impostos, câmbio, licenças de assinatura ou modelos trazidos de serviços externos.

Harness: construção, testes e avaliações também podem consumir créditos. Esse consumo adicional não é quantificado pelas entradas de uso desta ferramenta. Heavy tem apenas um mínimo, sem teto definido. Não é o serviço de programação GitHub Copilot.

Standard: a inclusão Microsoft 365 depende de uso autenticado elegível, no canal Microsoft 365 e dentro das condições de licença. CUA e fluxos com outros gatilhos continuam cobrados. As ações de fluxos são informadas como volume mensal executado, não apenas quantidade de fluxos configurados.
